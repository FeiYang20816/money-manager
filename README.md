# Money Manager

个人自用 Android 记账 App 项目仓库，包含可安装的 Android 首版和网页版原型。

## Android 安装版

- 安装包：[下载 v0.1.0 APK](https://github.com/FeiYang20816/money-manager/releases/download/v0.1.0/money-manager-0.1.0.apk)；本机生成文件位于 `dist/`。
- 安装与使用：[Android安装与使用.md](Android安装与使用.md)
- 源码与构建说明：[android/README.md](android/README.md)
- 适配目标：vivo S19 Pro / Android 16；最低 Android 8.0。

首版沿用已确认的界面，加入 SQLite 本地保存、系统文件导入导出、月末/年末总结通知、独立快捷记账窗口。首次安装为空账本；网页中的数据需要导出 JSON 后导入 App。应用内不包含示例账单。

安装后在“我的 → 总结提醒”开启通知，在“我的 → 快捷记账”添加桌面入口。总结在每月最后一天形成，晚上 9 点安排提醒；12 月 31 日同时提醒年度总结。后台调度受系统省电设置影响，可能延迟。

当前已完成编译和签名，用户已实际体验基础界面与功能。安装包通过 GitHub Release 分发；构建工具和个人签名材料保存在本机，未纳入 Git。月末和年末通知仍需到相应日期确认送达。

## 查看网页版

打开 [web/index.html](web/index.html) 即可预览。手机浏览器和电脑浏览器都可以使用；电脑上会显示手机外观预览。

网页版包含四个底部页面：首页、账单、统计、我的。可以记一笔、编辑和删除账单，搜索、切换月份、查看日历和统计；“我的”中可查看资产和自动总结，并下载 JSON 备份、导出或导入 CSV。首次打开会载入示例账单，后续改动保存在当前浏览器。

首页“最近 5 天账单”按自然日显示，账单页会持续标记今天。单笔支出超过 50 元时显示“奢侈消费”；备注包含“校园卡”的记录不计入该项。总资产按“期初资产 + 已记录收入 − 已记录支出”计算。月末和年末自动形成报告，若当时未打开网页，下次打开会补齐。

网页原型用于确认界面与流程。清除浏览器数据可能删除网页中的账单；如需保留，请在“我的”页面下载备份。JSON 备份会包含期初资产设置；CSV 只包含账单记录。
